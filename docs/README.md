# PrivacyGuard Wiki

Task-oriented guides — "I want to do X" rather than a feature-by-feature
list. The main [README](../README.md) documents every module and menu
option in full; this wiki is the shorter path to actually using them.

- **[Quick Start](01-quick-start.md)** — pick your environment
  (Termux / single Kali VM / two-VM gateway), get running in the
  fewest steps.
- **[Recommended Configurations](02-recommended-configs.md)** — a
  decision tree: given what you're trying to do, exactly what to
  enable and in what order.
- **[Persistent Logs & RAM Wipe](03-logs-and-ram-wipe.md)** — the
  exact steps for encrypted session logs, saved proxy/bridge profiles,
  on-demand RAM wipe, and the automatic shutdown hook.
- **[Troubleshooting](04-troubleshooting.md)** — fixes for the
  problems people actually hit, including "I enabled the kill switch
  and lost internet."

If something's missing here, it's worth a GitHub issue — this wiki
grows from real questions, not a feature checklist.
